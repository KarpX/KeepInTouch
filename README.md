# KeepInTouch
## Удобный сервис хранения телефонных контактов

### Целевая аудитория
- HR-менеджеры: для управления базой кандидатов.
- Офис-менеджеры: для хранения контактов подрядчиков и партнеров.
- Обычные пользователи: которым нужен удобный и доступный с любого устройства агрегатор личных связей.

### Описание предметной области
Сервис работает в рамках системы управления взаимоотношениями. Основной упор делается на персонализацию и быструю навигацию. В системе учитывается, что один контакт может иметь несколько способов связи и принадлежать к разным группам.

### Основные сущности
- Пользователь (User)
- Контакт (Contact)
- Средство связи (CommunicationChannel)
- Группа/Категория (Group)

### Основные функции
- Управление контактами (CRUD): создание, просмотр, редактирование и удаление карточек.
- Умный поиск: поиск по имени, номеру телефона, компании.
- Избранное: быстрый доступ к наиболее часто используемым контактам.

### План развития проекта
#### Этап 1: MVP (Минимально жизнеспособный продукт)

- Настройка проекта на Django, создание модели User.

- Регистрация и авторизация: личное пространство для каждого пользователя.

- Реализация основных моделей (User, Contact, Group).

- Создание базовых форм и представлений для CRUD-операций.

- Простой интерфейс на Bootstrap или стандартных Django-шаблонах.
#### Этап 2: Расширение функционала

- Реализация поиска и фильтрации.

- Группировка: возможность распределять людей по папкам.

- Возможность загрузки аватарок для контактов.

- Добавление нескольких номеров телефонов и email для одного контакта.

- Импорт/Экспорт: возможность выгрузки базы в формат CSV.

- Напоминания: (опционально) уведомления о днях рождения.
#### Этап 3: UX/UI и интеграции

- Улучшение дизайна.

- Реализация импорта/экспорта в CSV/Excel.

- Система уведомлений о днях рождения на email.
#### Этап 4: API и безопасность

- Разработка REST API (Django REST Framework) для возможного мобильного приложения.

- Двухфакторная аутентификация.
